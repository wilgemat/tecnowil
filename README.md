## Descripción

Página web multi-página desarrollada para la entrega final del Laboratorio de Programación.

Incluye:
- Home con presentación y servicios
- Página de servicios con acordeón de preguntas frecuentes
- Página de contacto con formulario y mapa
- Diseño responsive (mobile, tablet y desktop)
- Maquetado con CSS propio (flex, grid y media queries)
- 2 animaciones con keyframes
- Componentes de Bootstrap (navbar y accordion)
